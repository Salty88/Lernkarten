⚙️ GitHub-Verbindung

Deine Karten werden als JSON-Datei in einem GitHub-Repository gespeichert. So funktioniert die Synchronisierung zwischen Mac und Android: beide laden und speichern über dasselbe Repository. Der Lernstoff (lernstoff.json) und die Bilder (Ordner images/) liegen im selben Repository neben der Kartendatei.
Fine-grained Token, nur für dieses eine Repository, mit Berechtigung "Contents: Read and write". Wird nur lokal in diesem Browser gespeichert, nie im Repository selbst. Muss auf jedem Gerät (Mac, Android) einmal eingegeben werden.

Neuer Lernstoff

Leerzeile = neuer Absatz. Zeilen mit "- " am Anfang werden zur Aufzählung. **Text** wird fett.
Bilder werden vor dem Hochladen automatisch verkleinert und im Ordner images/ deines Repositories gespeichert.
